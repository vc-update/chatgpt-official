## 镜像网站是否可靠：七项检查

### 1. 看账号体系

第三方平台应使用自己的账号体系。要求输入 OpenAI 密码、验证码、恢复码或让客服远程登录的页面，应立即关闭。

### 2. 看域名和 HTTPS

从收藏夹或可信文章进入后，再检查最终域名是否一致。不要只看 Logo、页面颜色或“官方同款”文案，也不要在多次跳转后的陌生域名付款。

### 3. 看模型说明

平台应明确模型名称和可用范围。若只写“最强模型”“官方旗舰”却不显示具体选项、限制和更新时间，可信度会降低。

### 4. 看隐私政策

重点找聊天记录保存、文件处理、日志、账户注销和联系方式。没有隐私说明的平台，不适合处理文件、代码和个人信息。

### 5. 看客服与长期维护

短期能打开不等于长期稳定。检查是否有持续更新、明确客服渠道和故障说明，不要把整个工作流绑定在单一入口上。

### 6. 用低风险任务测试

第一次使用只提交公开材料，测试回答完整性、模型切换、文件解析和历史记录。确认功能符合页面描述后，再决定是否长期使用。

### 7. 看退出与数据删除能力

使用后检查能否退出账号、删除对话、清理文件或注销账户。公共电脑和共享设备上不要让浏览器保存平台密码。

## 哪些“镜像网站”不建议使用

- 要求输入 OpenAI 官方账号密码、验证码或恢复码。
- 宣称自己是 OpenAI 官方中国站，却无法给出可核验的官方关系。
- 通过网盘、群文件或陌生安装器提供所谓破解版客户端。
- 页面频繁跳转域名，付款页面与登录域名没有清晰关系。
- 不提供隐私政策、客服方式、账号删除或数据说明。
- 承诺永久稳定、绝对不限量、所有模型完全等同官网。
- 诱导上传身份证、银行卡、合同原件、客户资料或生产密钥。

## 使用镜像网站的安全清单

1. 给第三方平台设置独立密码，不与邮箱、OpenAI 或其他重要账号共用。
2. 不提交 OpenAI 密码、短信验证码、API Key、Cookie 或恢复码。
3. 文件先脱敏，移除个人信息、客户数据、金额、合同编号和内部标识。
4. 重要回答交叉核验，尤其是法律、医疗、金融、论文引用和生产代码。
5. 保留第二个备用入口，但不要重复存放敏感历史记录。
6. 模型、额度和功能以登录后的当前页面为准，不只看搜索摘要或推荐文章。

## 常见问题

### ChatGPT 国内镜像网站是官网吗？

不是。国内镜像网站、中文版工具站和多模型平台通常由第三方运营。ChatGPT 官方入口仍以 `chatgpt.com` 和 OpenAI 官方页面为准。

### 国内镜像网站可以使用 OpenAI 账号登录吗？

不建议在第三方页面输入 OpenAI 密码或验证码。本文列出的平台使用独立账号体系，账号和聊天记录不会自动与官网同步。

### 哪个镜像网站更适合文件和图片？

从当前功能定位看，GPTCat 更偏文件、图片、语音视频和综合内容工作流；先用公开或脱敏材料测试实际能力。

### 哪个平台更适合 Codex 和代码任务？

ZeoGPT 更偏 Codex、代码和长文档场景。使用前仍应删除密钥和内部信息，并对生成代码进行本地测试与人工审查。

### 镜像网站可以上传公司文件吗？

不应直接上传未经批准的公司文件。即使平台支持文件解析，也要先遵守公司制度、完成脱敏，并核对平台的数据保存和删除规则。

### 为什么同一个模型在不同网站回答不一样？

平台可能使用不同系统提示词、上下文长度、参数、工具、模型版本或内容处理流程。模型名称相同，不代表输出和官网完全一致。
