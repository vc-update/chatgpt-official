# ChatGPT 中文提示词大全：写作、办公、代码与图片 Prompt 模板【2026年8月】

<p class="update-note">更新日期：2026-08-02。本文适合搜索 `ChatGPT提示词`、`ChatGPT Prompt`、`ChatGPT指令大全` 的用户。</p>

ChatGPT 的效果，很大程度取决于你是否把任务讲清楚。新手常犯的错误是只问“帮我写一下”，结果模型只能给出泛泛的答案。更好的做法是告诉它：你是谁、要做什么、背景是什么、输出格式是什么、有哪些限制。

## 通用提示词公式

```text
你是一名 [角色]。
我的目标是 [任务]。
背景信息是：[上下文]
请输出为 [格式]。
限制条件：[风格、字数、语气、必须包含/避免的内容]。
如果信息不足，请先问我最多 3 个问题。
```

## 写作提示词

```text
你是一名中文内容编辑。
请根据下面主题写一篇文章大纲。
主题：[主题]
目标读者：[读者]
搜索关键词：[关键词]
要求：包含 H1、H2、H3、FAQ 和自然内链建议，不要夸张营销。
```

```text
请把下面文字改写得更自然、更像真人表达。
保留原意，不要新增事实。
语气：[专业/轻松/简洁/销售/学术]
原文：[粘贴内容]
```

## 学习提示词

```text
你是一名耐心的老师。
请用中文解释 [概念]。
要求：先给一句话解释，再给类比，再给 3 个例子，最后出 5 道自测题。
```

## 办公提示词

```text
请把下面会议记录整理成：
1. 会议结论
2. 待办事项
3. 负责人
4. 截止时间
5. 风险提醒
会议记录：[粘贴内容]
```

## 翻译提示词

需要处理 PDF、论文、术语表或长文分段时，可先阅读 [ChatGPT 翻译完整教程](/guides/chatgpt-translation-pdf-paper-prompts-guide-20260809)，再根据任务调整下面的简版提示词。

```text
请把下面英文翻译成自然中文。
要求：不要逐字硬翻，保留专业术语，并在最后列出术语表。
英文：[粘贴内容]
```

## 代码提示词

```text
你是一名资深软件工程师。
请分析下面报错的原因，并给出排查步骤。
技术栈：[语言/框架]
期望行为：[目标]
报错信息：[粘贴报错]
相关代码：[粘贴代码]
```

## SEO 提示词

```text
你是一名 SEO 编辑。
请围绕关键词 [关键词] 设计一篇能覆盖搜索意图的文章结构。
要求：给出标题、描述、H2/H3、FAQ、内链锚文本和首段写法。
避免：关键词堆砌、伪官方、夸张承诺。
```

## 图片生成提示词

```text
请为 [用途] 生成一段图片提示词。
画面主题：[主题]
风格：[写实/插画/产品图/科技感]
构图：[横版/竖版/居中/留白]
要求：不要文字、不要水印、不要品牌 logo。
```

## 让回答变好的追问

- “请用表格重排。”
- “请压缩到 5 条。”
- “请给出可执行步骤。”
- “请指出上面回答的风险。”
- “请基于我给的资料重写，不要新增事实。”
- “请分别给新手版和专业版。”
