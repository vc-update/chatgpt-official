# 关于 ChatGPT 独立指南

`chatgpt-official.com` 是面向中文用户的独立 AI 使用指南站，整理 ChatGPT 官方入口核验、中文使用、账号与浏览器故障、文件和图片工作流，以及相关 AI 工具的使用边界。

本站不属于 OpenAI，也不代表 ChatGPT 官方立场。ChatGPT 官方产品和公司信息应以 `chatgpt.com`、`openai.com` 及其当前官方帮助页面为准。

## 谁在编辑本站

站内内容由 **ChatGPT 独立指南编辑部** 维护。文章优先解决中文用户的具体任务，并尽量给出可复现的检查顺序、页面核验日期和一手信息来源。

本站不会因为域名中包含 `chatgpt-official` 而自称 OpenAI 官方网站，也不会要求读者把 OpenAI 密码、验证码或 API Key 提交给本站。

## 我们怎样核验内容

- 官方入口、状态和产品边界优先参考 OpenAI 官方页面；
- 故障文章通过短消息、无痕窗口、网络切换、附件拆分等可复现步骤组织；
- 涉及随账号、地区或时间变化的信息，避免给出永久不变的承诺；
- 文章标注首次发布、最后核验和修订记录；
- 发现错误时优先修订原 URL，不批量创建同义页面。

详细规则见 [编辑与内容政策](/editorial-policy)。

## 商业关系

部分国内使用、第三方工具或故障应急文章会包含推广链接。相关链接使用 `rel="nofollow sponsored"`，并明确说明第三方平台不属于 OpenAI 官方服务。

本站不以付费合作替代事实核验。推荐只应出现在与国内访问、多模型、文件、多模态或开发任务直接相关的页面中。读者在第三方平台提交内容前，应独立核对隐私、账号、文件保留和功能规则。

## 更正与联系

如果你发现文章中的官方入口、帮助链接、功能说明或排查步骤已经变化，可通过站点关联渠道反馈，并附上页面 URL、问题位置和可核验来源。编辑部会优先修订可能影响账号安全、隐私或操作结果的错误。
