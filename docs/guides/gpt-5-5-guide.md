## GPT-5.5 适合哪些任务

| 任务 | 适合程度 | 建议 |
| --- | --- | --- |
| 中文写作 | 高 | 给出素材和语气要求 |
| 办公总结 | 高 | 用表格和清单限制输出 |
| 代码开发 | 高 | 提供技术栈和报错 |
| 学习辅导 | 高 | 要求例子和自测题 |
| 图片生成 | 视平台而定 | 可配合 GPT-image-2 或 MJ |
| 实时信息 | 视平台而定 | 需要确认是否支持联网 |

## GPT-5.5 和其他模型怎么搭配

- GPT-5.5：综合任务首选。
- Claude 4.8：长文档、写作和分析。
- Gemini 3.1 Pro：多模态和资料处理。
- Grok 4.3：快速问答和轻量探索。
- DeepSeek-V3：中文、代码和推理性价比。

如果平台支持多模型，可以把同一个问题分别发给 2-3 个模型，再综合答案。

## GPT-5.5 提示词模板

```text
你是一名 [角色]。
请完成 [任务]。
背景信息：[上下文]
请先给结论，再给步骤，最后给风险提醒。
输出格式：[表格/清单/代码块/文章结构]
```

## 使用建议

1. 复杂任务拆分，不要一次塞太多目标。
2. 要求模型先问问题，再生成最终答案。
3. 用“请检查上面回答的漏洞”做二次审查。
4. 重要事实必须核验。
5. 长文档任务保留原始资料，避免模型凭空补充。
