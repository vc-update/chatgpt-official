# 隐私声明

*最后更新：2026年8月5日*

欢迎访问 chatgpt-official.com。本站非常重视用户隐私，并以简单、透明的方式说明本站如何处理信息。

## 本站不会主动要求你提交个人资料

本站是一个静态内容网站，主要提供 ChatGPT 官方入口、官网登录、中文版使用和国内访问说明。本站不开放注册功能，不要求用户登录，也不会要求用户填写表单或提交个人资料。

因此，本站不会通过账号、会员、评论或联系表单主动要求你提交以下资料：

- 姓名、手机号、邮箱地址
- 身份证号、银行卡号、支付信息
- 账号密码、聊天内容或其他敏感资料
- 可用于识别个人身份的用户资料

## 托管与基础技术日志

本站是静态内容网站，不建立用户账号数据库。但网站托管、CDN、DNS 和安全服务提供商可能为了提供页面、识别攻击和排查故障，处理 IP 地址、User-Agent、访问时间、请求 URL、来源页面和错误日志等基础技术数据。

这些数据由相关基础设施按照其服务规则处理。本站不会承诺互联网访问“绝对没有泄露风险”，也不会把基础技术日志描述为完全不存在。

## 第三方链接说明

本站文章中可能包含 OpenAI 官网、AI 工具平台或其他第三方网站链接。这些网站由第三方独立运营，其隐私政策、账号体系和数据处理方式不受本站控制。

当你离开本站并访问第三方网站时，请自行阅读并了解对应网站的隐私政策。请勿在任何不可信网站输入身份证号、银行卡号、账号密码等敏感信息。

## Cookie 与统计

本站当前不提供自建用户画像系统。如果使用基础访问统计或站点性能工具，会尽量减少数据范围，并在本页更新相应说明。浏览器和第三方服务是否设置 Cookie，还可能取决于其当前实现和用户设置。
